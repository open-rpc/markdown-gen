<div>
  # eth\_getFilterLogs



  Returns an array of all logs matching the filter with the given ID (created using \`eth\_newFilter\`).

  <div>
    ## Parameters

    **Filter identifier** `string`


  </div>

  <div>
    ## Result

    <div>
      **Log objects** *oneOf* `array or array`



      <details>
        <summary>
          Show Option 1 `Log objects` array
        </summary>

        #### `Log objects` fields



        **Log objects** `string`


      </details>

      <details>
        <summary>
          Show Option 2 `Log objects` array
        </summary>

        #### `Log objects` fields



        **Log objects** `object`



        <div>
          <details>
            <summary>
              Show `Log objects` object
            </summary>

            #### `Log objects` fields



            * **removed** `boolean`



            * **logIndex** `string`



            * **transactionIndex** `string`



            * **transactionHash** `string`



            * **blockHash** `string`



            * **blockNumber** `string`



            * **blockTimestamp** `string`



            * **address** `string`



            * **data** `string`



            * **topics** `string`


          </details>
        </div>
      </details>
    </div>
