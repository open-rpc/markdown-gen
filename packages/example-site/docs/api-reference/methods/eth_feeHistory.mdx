# eth_feeHistory

Returns transaction base fee per gas and effective priority fee per gas for the requested/supported block range.


---

## Method

- **JSON-RPC method name:** `eth_feeHistory`
- **JSON-RPC version:** `2.0`

## Parameters

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| blockCount | `string` | yes | Requested range of blocks. Clients will return less than the requested range if not all blocks are available. |
| newestBlock | `oneOf` | yes | Highest block of the requested range. |
| rewardPercentiles | `number[]` | yes | A monotonically increasing list of percentile values. For each block in the requested range, the transactions will be sorted in ascending order by effective tip per gas and the corresponding effective tip for the percentile will be determined, accounting for gas consumed. |
