    # eth\_sendTransaction



    Signs and submits a transaction.

    <div>
      ## Parameters (by position)

      **Transaction** `object` *required*

      Transaction object generic to all types

      <div>
        <details>
          <summary>
            Show `Transaction` object
          </summary>

          #### `Transaction` fields



          * **type** `string`

            type

          * **nonce** `string`

            nonce

          * <div>
              **to** `null or string`



              <details>
                <summary>
                  Show Option 1 `to` null
                </summary>

                #### `to` fields



                **to** `null`

                Contract Creation (null)
              </details>

              <details>
                <summary>
                  Show Option 2 `to` string
                </summary>

                #### `to` fields



                **to** `string`

                Address
              </details>
            </div>

          * **from** `string`

            from address

          * **gas** `string`

            gas limit

          * **value** `string`

            value

          * **input** `string`

            input data

          * **gasPrice** `string`

            The gas price willing to be paid by the sender in wei

          * **maxPriorityFeePerGas** `string`

            Maximum fee per gas the sender is willing to pay to miners in wei

          * **maxFeePerGas** `string`

            The maximum total fee per gas the sender is willing to pay (includes the network / base fee and miner / priority fee) in wei

          * **maxFeePerBlobGas** `string`

            The maximum total fee per gas the sender is willing to pay for blob gas in wei

          * **accessList** `array<object>`

            EIP-2930 access list

            <div>
              <details>
                <summary>
                  Show `accessList` object
                </summary>

                #### `accessList` fields

                EIP-2930 access list

                * **address** `string`

                  hex encoded address

                * **storageKeys** `array<string>`

                  32 byte hex value
              </details>
            </div>

          * **blobVersionedHashes** `array<string>`

            List of versioned blob hashes associated with the transaction's EIP-4844 data blobs.

          * **blobs** `array<string>`

            Raw blob data.

          * **chainId** `string`

            Chain ID that this transaction is valid on.

          * **authorizationList** `array<object>`

            EIP-7702 authorization list

            <div>
              <details>
                <summary>
                  Show `authorizationList` object
                </summary>

                #### `authorizationList` fields

                EIP-7702 authorization list

                * **chainId** `string`

                  Chain ID on which this transaction is valid

                * **nonce** `string`

                  nonce

                * **address** `string`

                  hex encoded address

                * **yParity** `string`

                  The parity (0 for even, 1 for odd) of the y-value of the secp256k1 signature

                * **r** `string`

                  r

                * **s** `string`

                  s
              </details>
            </div>
        </details>
      </div>
