<div>
  # eth\_syncing



  Returns an object with data about the sync status or false.

  <div>
    ## Parameters

    This method does not accept any parameters.
  </div>

  <div>
    ## Result

    <div>
      **Syncing status** *oneOf* `object or boolean`



      <details>
        <summary>
          Show Option 1 `Syncing status` object
        </summary>

        #### `Syncing status` fields



        **Syncing status** `object`



        <div>
          <details>
            <summary>
              Show `Syncing status` object
            </summary>

            #### `Syncing status` fields



            * **startingBlock** `string`



            * **currentBlock** `string`



            * **highestBlock** `string`


          </details>
        </div>
      </details>

      <details>
        <summary>
          Show Option 2 `Syncing status` boolean
        </summary>

        #### `Syncing status` fields



        **Syncing status** `boolean`

        Should always return false if not syncing.
      </details>
    </div>
  </div>

  <div>
    ## Examples

    <details>
      <summary>
        eth\_syncing example
      </summary>

      #### Request

      ```json
      {
        "params": []
      }
      ```

      #### Response

      ```json
      {
        "Syncing status": {
          "startingBlock": "0x0",
          "currentBlock": "0x1518",
          "highestBlock": "0x9567a3"
        }
      }
      ```
    </details>
  </div>
