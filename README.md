# markdown-gen

To install dependencies:

```bash
bun install
```

To run tests:

```bash
bun test
```

This project was created using `bun init` in bun v1.3.1. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.

### Watching the build

```bash
# Turn on the root watcher for auto rebuilding the example site on updates to plugin or generator
bun watch.ts
```
